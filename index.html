6 Algorithms — Details
Dijkstra
Graph · Greedy · Shortest Path
Finds the nearest available driver from customer's location. Also computes the optimal route from pickup to drop-off across the city road graph.
Time: O((V+E) log V)   Space: O(V)
Bellman-Ford
Graph · DP · Negative Weights
Handles traffic penalties (negative-weight edges). Detects negative cycles in the road network. Used for traffic-aware routing in the algorithm menu.
Time: O(V × E)   Space: O(V)
Prim's MST
Graph · Greedy · Spanning Tree
Builds the minimum spanning tree of all city zones using a priority queue. Shows the minimum road infrastructure needed to connect every location.
Time: O((V+E) log V)   Space: O(V)
Kruskal's MST
Graph · Union-Find · Spanning Tree
Sorts all roads by distance and uses Union-Find (DSU) to build the MST. Compared side-by-side with Prim's — both give equal total cost.
Time: O(E log E)   Space: O(V)
LCS
DP · Subsequence · Route Analysis
Finds the Longest Common Subsequence between two customers' location visit histories. Identifies shared travel zones — useful for carpooling suggestions.
Time: O(m × n)   Space: O(m × n)
LIS
DP · Subsequence · Trend Analysis
Finds the Longest Increasing Subsequence of a driver's ride durations over time. Identifies whether a driver is getting faster or slower across their trips.
Time: O(n log n)   Space: O(n)
